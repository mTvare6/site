Work Experience

Contributor — Graphite Editor Rust · wgpu · Vello · ~25k★

github.com/GraphiteEditor/Graphite · May ’25 – Sep ’25

Worked on Graphite, a Rust 2D vector graphics editor, as part of the 2025 Google Summer of Code program, merging 45+ PRs across the editor and its rendering stack.

Worked on large bitmaps used to pass through base64-encoded SVG image data, which made the preview stutter. I moved that pixel data to an off-screen HTMLCanvas cache using JavaScript's Reflect API and bitmap-heavy documents became much smoother to work with.

Added performance-aware masking to Graphite which in turn supports more features such as inverted masks, stroke alignment, and custom paint ordering. I implemented luminance-based clipping in Vello and updated Graphite's codebasee to Vello v0.5.0 and WGPU v25 so the editor could use it.

Built Blender-style transformation pivots where each layer has its own origin, and the Select and Path tools can switch between Active Object and Average of Origins while editing.

Implemented level ancestory queries to return the set of nodes at their shallowest common level for shallow selection option.

A lot of the work was smaller fixes such as transform cage fixes, node deserialization, isometric grids that didn't persist, and undo bugs when switching tools to name a few and many more math issues boundary edge cases and off-by-one issues.
